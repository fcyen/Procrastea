1. This is our design process, go through each step one by one. Every step is only completed when there is a deliverable added to the repo that fulfills the acceptance criteria. Steps marked with ✅ are already completed by your human team members. Steps marked with 🟡 are partially done. 

    1. UX research ✅
    2. Design principle ✅
    3. Information Architecture (IA) ✅
    4. User persona ✅
    5. User flow ✅
    6. Low fidelity Wireframe 🟡
        - Do:
            - split `procrastinatea_wireframes.html` into smaller files so you don't have to load everything when making changes to one screen
            - some of the wireframes need major modifications, the sketches can be found in /wireframe-references
            - for the group screen, I am thinking of something similar to the setlog UI, but with affordances to approve a friend's habit, please design something based on that.
            - for the calendar (statistics) screen, there is a reference, but I am open to suggestions.
        - Acceptance criteria: wireframes for all screens, covering all interactions in the user flow
    7. Branding guide 🟡
        - Acceptance criteria: full set of logo, colour pallete, typeface, UI components
    8. High fidelity wireframe
        - Acceptance criteria: same screens as low fidelity wireframe, but adopts the branding guide. May be combined with Prototype in the next step if makes sense.
    9. Prototype
    10. Testing
        - Acceptance criteria: analysis on feedback from users after trying the prototype
    11. Refine
        - Acceptance criteria: addressed the feedback from the previous step

2. Pause the loop and ask for human inputs in the following scenarios:

    1. Not enough information to proceed to the next steps
    2. Found opportunity to improve or refine existing work that is not part of the current step
    3. Completed a step, ask human to validate deliverable

3. Break steps down into smaller steps whenever necessary.
