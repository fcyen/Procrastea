# Step 6 — Low fidelity wireframe

## Goal
Complete the low-fidelity wireframes for every screen of the Procrastinatea
habit-tracking app, covering all interactions in the user flow.

## Inputs
- `procrastinatea_wireframes.html` — the current (partial) wireframes
- `wireframe-references/` — sketches for screens that need major modifications
  (Homepage, Intro Screen, New habit, Select habit, Customize habit, Tracking,
  Calendar reference)
- `raw files/User Flow.png` — the user flow every interaction must map to
- `raw files/Information Architecture.png`

## Instructions (from LOOP.md)
1. Split `procrastinatea_wireframes.html` into smaller per-screen files
   (e.g. under `wireframes/`) so a change to one screen doesn't require
   loading everything.
2. Some wireframes need major modifications — follow the sketches in
   `/wireframe-references`.
3. Group screen: design something similar to the setlog UI, but with
   affordances to approve a friend's habit. There is no sketch for this —
   propose a design and flag it for human review.
4. Calendar (statistics) screen: there is a reference
   (`wireframe-references/Calendar (reference).png`), but suggestions are
   welcome.

## Acceptance criteria
Wireframes exist for all screens, covering all interactions in the user flow.

## Format conventions (from CLAUDE.md)
Wireframes/mockups are HTML and CSS.
