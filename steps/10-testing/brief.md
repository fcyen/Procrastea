# Step 10 — Testing

## Goal
Analyse feedback from users after they try the prototype.

## Notes
This step depends on human-collected input (user testing sessions). Expect to
call the ask_human tool (type "blocked") to request the raw feedback if it is
not already in the repo, then produce the analysis.

## Acceptance criteria
An analysis (Markdown) of feedback from users after trying the prototype:
themes, severity, and recommended changes.
