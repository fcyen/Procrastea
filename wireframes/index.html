Procrastea — Low-fidelity Wireframes

Nineteen mobile screens mapped from the user flow. The product rests on one loop: complete a habit, snap a photo as proof, and your group approves it and cheers you on — so photo-proof and the social feed are the spine of every screen. Each screen lives in its own file under screens/ and shares one stylesheet, so any single screen can be edited in isolation.

Green = primary action / active state Hatched box = habit photo (proof) Green toggle = enabled
