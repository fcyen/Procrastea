# Procrastea — design process deliverables

This folder holds the write-ups for each step of the design process (see `/LOOP.md`).
Steps 1–5 were completed by the team; the high-resolution source assets live in
[`/raw files/`](../raw%20files/) (Market Research, Information Architecture, User Flow,
Problem statement, User Personas), and the full FigJam board is archived at
[`/design-source/figjam-board.pdf`](../design-source/figjam-board.pdf).

| Step | Deliverable | Source |
|------|-------------|--------|
| 1. UX research | [`01-ux-research.md`](01-ux-research.md) | `raw files/Market Research.png`, `Problem statement.txt` |
| 2. Design principles | [`02-design-principles.md`](02-design-principles.md) | derived from research + personas (no standalone artifact) |

| 4. User personas | [`04-personas.md`](04-personas.md) | `raw files/User Personas.txt` (verbatim) |
| 5. User flow | [`05-user-flow.md`](05-user-flow.md) | `raw files/User Flow.png` (Mermaid) |
| 6. Low-fi wireframes | [`../wireframes/`](../wireframes/) | done |
| 7. Branding guide | [`../branding/`](../branding/) | done (logo direction pending pick) |
| 8–9. Hi-fi wireframes + prototype | [`../prototype/`](../prototype/) | combined per LOOP.md — all 19 screens, interactive |

Per `raw files/`, the wireframes (step 6) were checked against the real IA and user flow:
they align (photo-first logging, group feed with approval, the settings tree). Minor
reconciliation notes are recorded at the bottom of `05-user-flow.md`.
